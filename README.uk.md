# Голка Бюффона

[English version](README.md)

Це Manim-проєкт для створення відео про експеримент з голкою Бюффона.

## Мета

Проєкт створюється поступово, щоб зробити коротку математичну анімацію про експеримент з голкою Бюффона.

Ідея експерименту:

1. намалювати паралельні лінії;
2. кидати випадкові голки;
3. рахувати, скільки голок перетнули лінію;
4. оцінити експериментальну ймовірність

$$
P \approx \frac{M}{N}
$$

де:

- $N$ — загальна кількість кинутих голок;
- $M$ — кількість голок, які перетнули лінію;
- $P$ — експериментальна ймовірність перетину.

Після цього можна оцінити число $\pi$:

$$
\pi \approx \frac{2L}{dP}
$$

де:

- $L$ — довжина голки;
- $d$ — відстань між сусідніми паралельними лініями.

У спеціальному випадку $L=d$:

$$
\pi \approx \frac{2N}{M}
$$

## Поточний стан

Зараз у проєкті є перша Manim-сцена.

Вона:

- показує заголовок `Buffon's needle experiment`;
- малює кілька горизонтальних паралельних ліній;
- створює базове Manim-відео;
- перевіряє, що Manim налаштовано правильно.

Голки та підрахунок перетинів ще не додані.

- `buffon_scene.py` — Manim-сцена для першої частини відео про голку Бюффона.
- `pyproject.toml` — налаштування проєкту та залежності.
- `uv.lock` — зафіксовані версії залежностей.
- `README.md` — англійська версія README.

## Що потрібно для запуску

Проєкт використовує:

- Python;
- uv;
- Manim.

Залежності керуються через `uv`.

## Запуск тестового Python-файлу

```bash
uv run python main.py
```

Очікуваний результат:

```text
Hello from buffon-needle!
```

## Запуск Manim-сцени

```bash
uv run manim -pql buffon_scene.py ParallelLinesScene
```

Розшифрування команди:

- `uv run` — запуск команди всередині середовища проєкту;
- `manim` — запуск Manim;
- `-p` — відкрити відео після рендеру;
- `-q l` — швидкий рендер у низькій якості;
- `buffon_scene.py` — файл зі сценою;
- `ParallelLinesScene` — назва класу сцени.

## Наступні кроки

1. Розібрати код `buffon_scene.py` рядок за рядком.
2. Замінити ручні координати ліній на координати через відстань `d`.
3. Додати одну голку.
4. Навчитися перевіряти, чи перетинає голка лінію.
5. Додати багато випадкових голок.
6. Порахувати кількість перетинів.
7. Показати $P \approx M/N$ та оцінку $\pi$.
