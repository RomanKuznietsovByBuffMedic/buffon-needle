# Buffon Needle Manim

[English version](README.md)

Це Manim-проєкт для створення математичного відео про задачу Голки Бюффона.

Мета проєкту — візуалізувати:

- випадкове кидання голок;
- перетини з паралельними прямими;
- експериментальну оцінку числа \(\pi\);
- формулу ймовірності в задачі Голки Бюффона.

## Стан проєкту

Проєкт зараз перебуває на етапі налаштування та експериментів.

## Вимоги

Системні залежності:

- Python
- uv
- ffmpeg
- cairo
- pango

Для Arch Linux:

```bash
sudo pacman -S --needed python uv ffmpeg cairo pango
```

## Налаштування

Після клонування репозиторію виконайте:

```bash
uv sync
```

Це створить або оновить локальне віртуальне середовище `.venv` і встановить залежності з `uv.lock`.

## Рендер

Приклад тестового рендеру:

```bash
uv run manim -pql main.py TestCircle
```

Параметри:

```text
-p   відкрити попередній перегляд після рендеру
-q l низька якість, швидкий рендер
```

## Структура проєкту

```text
buffon-needle/
├─ .venv/              # локальне віртуальне середовище, не додається в Git
├─ .vscode/            # налаштування VS Code для проєкту
├─ main.py             # сцени Manim
├─ pyproject.toml      # опис проєкту та залежностей
├─ uv.lock             # зафіксовані версії залежностей
├─ README.md           # опис проєкту англійською
├─ README.uk.md        # опис проєкту українською
└─ media/              # згенеровані відео, не додаються в Git
```

```text
.venv/
media/

```
