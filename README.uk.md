# Голка Бюффона

[English version](README.md)

Це Manim-проєкт для створення відео про експеримент з голкою Бюффона.

## Мета

Проєкт створюється поступово, щоб зробити коротку математичну анімацію про експеримент з голкою Бюффона.

Ідея експерименту:

1. намалювати нескінченну підлогу з рівновіддаленими паралельними прямими;
2. кидати випадкові голки;
3. рахувати, скільки голок перетнули пряму;
4. оцінити експериментальну ймовірність

$$
P_{\mathrm{exp}} \approx \frac{K}{N}
$$

де:

- $N$ — загальна кількість кинутих голок;
- $K$ — кількість голок, які перетнули пряму;
- $P_{\mathrm{exp}}$ — експериментальна ймовірність перетину.

У спеціальному випадку $l=d$ теоретична ймовірність дорівнює

$$
P = \frac{2}{\pi}.
$$

Анімація експериментально показує, що

$$
\frac{2}{P_{\mathrm{exp}}} = \frac{2N}{K} \approx \pi,
$$

а потім приводить до формули

$$
P \approx \frac{2}{\pi}.
$$

## Поточний стан

Зараз у проєкті є фіналізована основна Manim-сцена для експериментальної частини відео.

Сцена:

- вводить ідею нескінченної підлоги з рівновіддаленими паралельними прямими;
- малює довгі горизонтальні паралельні прямі, які виходять за межі кадру;
- показує відстань $d$ між сусідніми прямими;
- показує спеціальний випадок $l=d$;
- демонструє випадкове кидання голки через випадкову позицію та випадковий кут;
- показує, чи перетинає голка пряму;
- рахує загальну кількість кидків і кількість перетинів;
- показує великий змодельований експеримент;
- виводить візуальний зв'язок між експериментальною ймовірністю та числом $\pi$;
- завершується переходом до доведення.

## Файли

- `main.py` — простий тестовий Python-файл.
- `buffon_scene.py` — Manim-сцена для експерименту з голкою Бюффона.
- `pyproject.toml` — налаштування проєкту та залежності.
- `uv.lock` — зафіксовані версії залежностей.
- `README.md` — англійська версія README.

## Що потрібно для запуску

Проєкт використовує:

- Python;
- uv;
- Manim.

Залежності керуються через `uv`.

## Запуск тестового Python-файлу

```bash
uv run python main.py
```

Очікуваний результат:

```text
Hello from buffon-needle!
```

## Швидкий попередній рендер

Для швидкої перевірки сцени використовуйте:

```bash
uv run manim -pql buffon_scene.py BuffonNeedleExperimentScene
```

Розшифрування команди:

- `uv run` — запуск команди всередині середовища проєкту;
- `manim` — запуск Manim;
- `-p` — відкрити відео після рендеру;
- `-ql` — швидкий рендер у низькій якості;
- `buffon_scene.py` — файл зі сценою;
- `BuffonNeedleExperimentScene` — назва класу сцени.

## Фінальний 4K-рендер

Для максимальної якості використовуйте:

```bash
uv run manim -qk buffon_scene.py BuffonNeedleExperimentScene
```

Готове відео буде збережено тут:

```text
media/videos/buffon_scene/2160p60/BuffonNeedleExperimentScene.mp4
```

## Якісний 1080p-рендер

Якщо 4K рендериться занадто довго, використовуйте:

```bash
uv run manim -qh buffon_scene.py BuffonNeedleExperimentScene
```

Готове відео буде збережено тут:

```text
media/videos/buffon_scene/1080p60/BuffonNeedleExperimentScene.mp4
```

## Де з'являється відео

Manim автоматично створює папку:

```text
media/
```

У ній зберігаються згенеровані відео.

Цю папку не треба додавати в Git, бо її можна створити повторним запуском Manim.

## Що не треба додавати в Git

Не треба комітити:

```text
.venv/

__pycache__/

```
